# Google Play listing assets

Captured from version 0.10.6 against the Aster Demo server, on the Pixel 10 and Pixel Tablet emulators.

| Play Console slot | Folder | Size |
| --- | --- | --- |
| App icon | `graphics/icon-512.png` | 512×512, 32-bit PNG |
| Feature graphic | `graphics/feature-graphic-1024x500.png` | 1024×500, 24-bit PNG |
| Phone screenshots | `phone/` | 1080×1920; player and disc menu are 1920×1080 |
| 7-inch tablet screenshots | `tablet-7in/` | 1920×1080 |
| 10-inch tablet screenshots | `tablet-10in/` | 2560×1440 |

The 7-inch set is the 10-inch captures scaled down, so it shows the same layout rather than a separate capture on a smaller screen.

Upload in filename order. Feature graphic alt text (140 characters or less):

> Aster: movies, TV, anime, music and audiobooks from your own server.

## Screenshot alt text

| File | Alt text |
| --- | --- |
| `01-home` | Aster's Home screen, with a full-screen featured title and a button to resume or play it. |
| `02-shelves` | Home shelves for Continue Watching, Up Next and Recently Added Movies. |
| `03-title-page` | The title page for the film Spring, with full-bleed art, its logo, details and a Play button. |
| `04-player` | The video player showing Sprite Fright, with skip buttons, a timeline, and speed and quality controls. |
| `05-disc-menu` | A DVD-style disc menu for Big Buck Bunny, with Play Movie, Commentaries, Special Features and Trailer. |
| `06-anime` (phone) | The Anime tab, featuring the series Morevna with a Resume button. |
| `06-channels` (tablet) | The Channels guide: playlists scheduled as TV channels, shown on a timeline. |
| `07-music` | The Now Playing screen for a Chopin prelude, with playback controls and Up Next. |
| `08-audiobook` | The audiobook player for The Adventures of Tom Sawyer, with chapter progress and skip controls. |
